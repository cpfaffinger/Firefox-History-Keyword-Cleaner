# Datenschutzerklärung / Privacy Policy

Gültig ab / Effective: 26. Juli 2026

## Deutsch

History Keyword Cleaner sammelt, überträgt, verkauft oder teilt keine
personenbezogenen Daten, Browseraktivitäten, Suchbegriffe, technischen Daten
oder Nutzungsanalysen.

Das Add-on verarbeitet die Firefox-Chronik ausschließlich lokal, um URLs und
Seitentitel mit den vom Benutzer definierten Keywords zu vergleichen.
Keywords, Einstellungen und aggregierte Löschzähler werden ausschließlich im
lokalen Add-on-Speicher des Firefox-Profils (`browser.storage.local`)
gespeichert. Sie werden nicht synchronisiert und nicht an externe Server
gesendet.

Das Add-on enthält keine Telemetrie, Werbung, Tracking-Pixel, externen Skripte
oder Netzwerkendpunkte. Beim Entfernen des Add-ons löscht Firefox dessen lokalen
Erweiterungsspeicher gemäß den Firefox-Speicherregeln.

Ein vom Benutzer ausgelöster Export erstellt lediglich eine lokale JSON-Datei.
Ein Import liest nur die vom Benutzer ausgewählte lokale JSON-Datei.

## English

History Keyword Cleaner does not collect, transmit, sell, or share personal
data, browsing activity, search terms, technical data, or usage analytics.

The add-on processes Firefox history only inside the local browser to compare
URLs and page titles with keywords defined by the user. Keywords, settings, and
aggregate deletion counters are stored only in the Firefox profile's local
extension storage (`browser.storage.local`). They are not synchronized or sent
to external servers.

The add-on contains no telemetry, advertising, tracking pixels, remote scripts,
or network endpoints. When the add-on is removed, Firefox handles removal of
its local extension storage according to Firefox storage behavior.

A user-initiated export only creates a local JSON file. An import only reads the
local JSON file selected by the user.
